# AI Usage

This project was developed with AI assistance.

AI was used for:
- workflow design review
- expression and code generation assistance
- debugging support
- error analysis
- documentation drafting
- alternative implementation suggestions

I personally:
- defined the problem and requirements
- built the n8n workflow node by node
- configured and connected each node
- tested routing and validation logic
- reviewed AI-generated suggestions
- modified implementations when needed
- verified outputs and workflow behavior
- made final design decisions

AI was used as an implementation and review tool, not as a substitute for validation or system ownership.
